# Inbox

Drop a Markdown file here to hand the harness a task without opening the web app.

- The first `# Heading` (or the file name) becomes the task title; the rest is the brief.
- Optional front matter: `lead: engineering`, `priority: 2`, `repo: /path/to/repo`.
- The file is moved to `data/inbox-processed/` once it has been picked up.
